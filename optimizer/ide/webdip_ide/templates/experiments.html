An experiment is a record the agent writes before it runs anything: one hypothesis, what it expects to see if the hypothesis is true and if it is false, and the rule the result will be read against. Then it builds the one change, plays the new version against the old one in the same games, and writes the verdict in the same file. Records appear here as soon as the file exists in experiments/.
