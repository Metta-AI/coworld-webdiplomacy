# Best practices — webDiplomacy

Durable, graduated practice for optimizing in this game. Lessons graduate here
from `TENTATIVE_LESSONS.md` when they recur across sessions (`lessons-review`),
each with its recurrence evidence.

This file ships with no entries: "what worked" is true of one lab and one field.
How to measure is in the skills ([ab](skills/ab/SKILL.md),
[survey](skills/survey/SKILL.md), [eval-design](skills/eval-design/SKILL.md)),
and the bot contract's safe phase loop is in [docs/protocol.md](docs/protocol.md).

Format (the block below is an example of the fields, not an entry):

```
## <area, e.g. Measuring>

- **<the practice, as an instruction>.** <when it applies and how to do it>
  *(Evidence: <experiment record ids or sessions where it recurred>)*
```
